# Где что лежит

Актуальное состояние: 27 октября 2026. Приложение без сборки: Node.js обслуживает статические файлы и небольшой HTTP API; SQLite встроен в Node.js.

## Пользовательский сайт — `public/`

| Файл | Что редактировать |
| --- | --- |
| `index.html` | Каркас сайта, шапка, подвал, подключения CSS/JS. |
| `portal.js` | Этапы подключения, кабинет, обработчики кнопок, отправка чека, состояния и предупреждения о дублях. |
| `portal.css` | Актуальное оформление сайта и мобильная версия. |
| `portal-model.js` | **Рублёвые тарифы**, базовый лимит 3, календарный расчёт срока, определение типов устройств, ссылки Incy. Этот модуль импортируется и сервером. |
| `account-ui.js` | Оплата, оферта, сохранённые вспомогательные шаблоны входа/продления. Наличие `loginPage()` не означает, что текущий сайт использует полноэкранный вход: сейчас вход открывается небольшим окном из `portal.js`. |
| `logo.svg` | Основной векторный знак Colors VPN. |
| `connect.html`, `connect.js` | Отдельная публичная карточка подключения `/connect`. |
| `connection-card.js`, `connection-content.js` | Разметка и тексты карточки подключения; в текстах ещё есть компенсация до **31 октября 2026**. Она не меняет срок в панели. |
| `admin.html`, `app.js`, `style.css` | Старое визуальное оформление админки и демо-клиента. Здесь же реализованы **очередь чеков нового сайта** и форма реквизитов в настройках. Это не главная страница текущего сайта. |

Изменения HTML/CSS/JS видны после обновления страницы. После изменения `portal-model.js` перезапустите Node: сервер импортирует цены и лимит в память при старте. Проверка цены в запросе защищает от отправки чека по устаревшей сумме.

## Сервер — `src/`

| Файл | Ответственность и границы |
| --- | --- |
| `main.js` | Точка входа: режим demo/production, каталоги данных, БД, сервер, таймер. При непустом `BOT_TOKEN` в non-demo запускает первоначальный Telegram polling — **не включать его для уже работающего бота Вани**. |
| `server.js` | Список обслуживаемых страниц и файлов, Host/Origin/CSP, HTTP-маршруты, разделение demo и production. Начинать подключение пользовательского API здесь. |
| `portal-demo.js` | Демонстрационная идентичность/подписка/сценарии. В рабочем демо хранит сессии в SQLite, cookie содержит случайный идентификатор. Не заменяет настоящего клиента backend. |
| `portal-payments.js` | Локальная очередь чеков, BLOB файлов, снимки RUB-тарифов, настройки реквизитов, ручное решение. Production-приём чеков отключён. |
| `telegram-login.js` | OIDC: PKCE, state, nonce, RS256, проверки claims, серверные сессии. Реальный внешний вход ещё не проверялся. |
| `remnawave-reader.js` | Серверный read adapter панели: статус, срок, ссылка, HWID-устройства. Пока не вызывается публичным API; сверить с установленной версией панели. |
| `account-links.js` | Отдельный неиспользуемый примитив одноразовой привязки в памяти. Не готовое постоянное хранилище аккаунтов. |
| `store.js` | SQLite-обёртка, старые заказы/подписки, аудит, outbox. OIDC и портал добавляют свои таблицы из соответствующих классов. |
| `service.js`, `telegram.js` | Первоначальный бот/Stars-прототип. Сохранён как наработка; это **не код действующего бота Вани** и не текущая RUB-очередь сайта. |
| `config.js`, `check.js` | Валидация и проверка конфигурации первоначального прототипа. `npm run check` ожидаемо сообщает о пустых production-настройках. |

## Конфигурация и данные

| Путь | Назначение |
| --- | --- |
| `config/manual-payment.json` | Изначально пустые банк, получатель, реквизиты и комментарий. Изменения из админки сохраняются в SQLite и имеют приоритет над этим файлом. |
| `config/demo.json` | Пример настроек старого Stars-прототипа. Его `stars` и `days` **не являются рублёвыми тарифами и календарными месяцами сайта**. |
| `config/settings.json` | Пустой production-шаблон первоначального бота; не автоматически готовая конфигурация backend Вани. |
| `data/demo/settings.json` | Создаётся из `config/demo.json` при первом запуске; локальные изменения демо. Исключён из Git. |
| `data/demo/vpn.sqlite` | Сессии, чеки и другие тестовые данные. Не включён в репозиторий и архив. |
| `data/production/` | Каталог non-demo-режима. Данные/секреты также исключены из Git. |
