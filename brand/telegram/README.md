## Цвета и шрифты

В аватаре оставлен только крупный знак. Для постов: короткий заголовок белым, смысловой акцент зелёным, один спокойный фон. Не добавляйте маленький текст внутрь аватара.

## Редактирование

Все макеты в `svg/` сохраняют редактируемые тексты и векторные формы. Открываются в SVG-редакторе. `svg/logo-original.svg` — исходный знак с сайта.

Сборщик: `tools/build-telegram-kit.cjs`. Он читает логотип и тарифы из текущих файлов сайта и экспортирует SVG/PNG; сайт не меняется. Для повторного экспорта нужен Node.js и доступный модуль `sharp` как служебная зависимость (например, `npm install --no-save sharp`, затем `node tools/build-telegram-kit.cjs`).

Тарифы в карточках: 250 / 550 / 990 / 1 850 ₽. После изменения цен на сайте заново экспортируйте карточки. Изображения сами не обновляются.
